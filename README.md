面向活动视频的脚本与分镜工作台：整理需求、创作与修订脚本、选择图片参考，并准备人工复核和交付。

## 启动

以下说明供维护者和另获授权的使用者使用。需要 Python 3.10、Git 和 [uv](https://docs.astral.sh/uv/)。

```sh
uv sync --locked --no-dev --python 3.10
./mplus doctor
./mplus ui
```

内部 Python 包和兼容命令暂时保留原名；对外项目展示名为 Loomtake。

首次启动需要在本机配置持久数据目录及实际使用的模型凭据。默认仅监听 `127.0.0.1:8765`。扫描 PDF 还需要 Poppler；浏览器测试需自行安装对应 Playwright 浏览器。
